LauncherX

简介

LauncherX 是由 Corona Studio 日冕工作室开发的下一代 MC 启动器
包含美观简洁的 UI 界面和强大的功能集成，旨在帮助玩家获得更好的游戏体验
前往官网下载最新稳定版：点击前往
访问知识库：点击访问

前言

在游玩mc时要想体验游戏，一款mc启动器是少不了的。在mc发展的15年历程中出现了各种各样的启动器，有官方的、也有大佬自制的。

功能介绍

可自定义的 UI


一键下载整合包、光影材质、MOD

包含以往版本下载、CurseForgr资源、Modrinth资源下载

内置游戏新闻，实时更新mc新闻消息

启动器内自带联机模式一键建房与好友畅玩

使用教程

下载

1.可以通过他们的官网下载官网下载链接
2.通过下载外链
2.1点击下载windows X64
2.2点击下载windows Arm64
2.3点击下载macOS lntel
2.4点击下载macOS Apple
2.5点击下载Linux X64
2.6点击下载Linux Arm
Java下载 如果没下载点击下载Java

启动

把下载好的 LauncherX 启动器解压，然后放到游戏目录如D/LauncherX/LauncherX.Avalonia.exe
点击LauncherX.Avalonia.exe，根据启动向导完成第一次启动。如 UI 界面(可更改)，登录方式 离线登录 正版登录…

用过其他启动器

完成后即可进入启动器，如果和其他启动器在一个目录(如pcl)点击 左下第2个游戏列表
如果有那就可以直接启动，
点击右边图钉图标，即可固定到主页快捷启动

未用过其他启动器

如果没有其他启动器，那就点击点击 左下第3个下载
根据自己需求下载
下载完成点击 左下第2个游戏列表
点击右边图钉图标，即可固定到主页快捷启动

注册和登录

点击 左下第4个设置
左上角第4个多人游戏

注册

电子邮箱，如；xxx.qq.comqq邮箱实例
用户名， 只能包含大小写字母，数字，横杠或下划线，长度为4-16
密码，长度为6-20，密码必须包含大小写字母，数字，横杠或下划线以外的特殊字符
